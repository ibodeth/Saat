# Saat

A minimal digital clock that floats on your desktop with a transparent background and no window frame.

## How it Works
The application uses Python's built-in Tkinter library to create a transparent, borderless window layer that displays the system time. Mouse click-and-drag interactions are mapped to window position offsets, allowing the clock to be positioned anywhere on the screen.

## Tech Stack
- **Languages/Frameworks:** Python, Tkinter
- **Services/Libraries:** N/A
- **Infrastructure:** Windows

## Local Setup
1. Clone the repository:
   ```bash
   git clone https://github.com/ibodeth/Saat.git
   cd Saat
   ```
2. Run the application:
   ```bash
   python main.py
   ```
